# 软件输出自动化 - 第一版骨架

这是项目的第一版原型骨架，目标是先把完整链路跑通：

1. 输入客户需求
2. AI 分析并生成结构化结果
3. 人工审核占位
4. 定位客户目录
5. 按固定规则修改文件
6. 触发编译占位
7. 为 MCP 接口预留调用能力

## 当前技术栈

- Python
- PySide6（UI）
- MCP 接口占位层
- 固定规则修改层

## 目录结构

- `main.py`：启动入口
- `ai/`：AI 分析占位
- `review/`：人工审核占位
- `customer_project/`：客户目录查找、复制、改名
- `rules/`：固定规则定义
- `patcher/`：规则执行器
- `builder/`：编译服务占位
- `executor/`：任务编排
- `ui/`：PySide6 界面
- `mcp/`：MCP 接口预留

## 第一版运行方式

```bash
python main.py
```

## 第一版 UI 功能

- 输入客户需求
- 指定客户工程根目录
- 一键执行任务
- 查看日志

## 当前版本边界

第一版只做：

- 一套代码工程
- 一个默认客户目录占位逻辑
- 一条最小闭环流程
- MCP 占位接口

不做：

- 真实 AI 调用
- 真实编译服务器接入
- 完整错误处理
- 完整 UI 设计
